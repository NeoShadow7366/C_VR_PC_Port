# Security & Takedown Policy

NeoXR Citra VR is an independent, non-commercial fan fork of
[CitraVR](https://github.com/amwatson/CitraVR), maintained by a single
hobbyist. This document describes how to report security issues, and how
rights holders can request takedowns or corrections.

## Reporting a security vulnerability

If you believe you have found a security vulnerability in this project
(e.g., an exploitable bug in the OpenXR / Vulkan glue code, the
installer, the Steam-shortcut writer, or the Qt frontend), please **do
not** open a public GitHub issue. Instead:

1. Open a private security advisory via GitHub:
   <https://github.com/NeoShadow7366/C_VR_PC_Port/security/advisories/new>
2. Or contact the maintainer through their GitHub profile:
   <https://github.com/NeoShadow7366>

Please include:

- A description of the issue and its potential impact.
- Steps to reproduce, or a proof-of-concept if available.
- The build / commit hash you tested against.

A best-effort response will be made within a reasonable time. Note that
this is a personal project with no SLA; please be patient.

## Trademark / copyright / DMCA notices

If you are a rights holder (or an authorised agent of one) and believe
that any content in this repository infringes your intellectual
property, please open a GitHub issue **or** contact the maintainer
through their GitHub profile linked above. Include:

- Identification of the work or trademark you believe is being
  infringed.
- The specific file path(s) or URL(s) in this repository.
- A description of the remedy you are seeking (removal, attribution,
  rename, etc.).
- Your contact information and good-faith statement.

The maintainer will respond promptly. Trademark concerns will be
addressed by renaming or removing the offending references; copyright
concerns will be addressed by removing the offending files.

## What this project does NOT distribute

For the avoidance of doubt, this project does **not** ship:

- Nintendo ROMs, save files, or game content of any kind.
- Nintendo 3DS firmware, BIOS, AES keys, or system files.
- Proprietary SDKs from Nintendo, Valve, Meta, or any other vendor.
- Any decryption tools targeting copy protection.

Users must supply their own legally-obtained 3DS software to use this
emulator.
